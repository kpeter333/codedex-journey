About

I'm Kelvin, a self-taught developer working through the Codedex curriculum one exercise at a time. I started with Python and I'm now building web pages by hand. This journal is where I write down what I learn so I don't have to learn it twice.

Stories

Why I started coding

I kept seeing people build things out of nothing but text in a file, and I wanted to know how. So I opened a tutorial and typed the first line. That was the entire plan, and it turned out to be enough.



My first Python bug

I spent forty minutes on a guessing game that congratulated me for wrong answers. The cause was a single line where I checked whether a variable existed instead of what it equalled. A non-empty variable is always true, so the first branch always won.



Learning HTML the slow way

Every tag I meet gets explained to me line by line before I move on. It feels slower than copying examples from a tutorial. But I can now read a page's structure and say why each element is there, so slow turned out to be faster.
