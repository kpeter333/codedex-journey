My First Python Bug

20 October 2026

I spent forty minutes on a guessing game that congratulated me for wrong answers. The cause was one line: I had written if answer: instead of if answer == number:

A non empty variable is always true, so the first branch always won. Lesson learned: say exactly what you mean.
